# 明日债 · Tomorrow's Debt

一款独立网页恐怖游戏（v0.2「凶契」）。**你要把一封契，送给死去的未来的自己。**

## 玩法

- 你没有武器，只有一支朱砂笔：**移动会拖出朱砂轨迹，绕着邪祟走满一圈、合拢成印，圈内的东西就被封杀。**圈越大收益越高，被围的风险也越大；冲刺能逃命，但会把印冲断。
- 三幕恐怖题材各异、主线贯通：雨夜凶宅 → 停尸走廊 → 血月祭坛。生命、构筑与命债跨幕继承，提灯的光圈之外皆是暗处。
- 借命三咒（阴爆 / 纸人环 / 凝时）随借随用，但每借一次记一笔命债：约 22 秒后，讨债影会带着你借的那一咒来讨债。
- 最终 Boss「大讨债影 · 死去的你」的咒组 = 你全程借过的咒集合。借得越少，终局越轻。
- 每波结束三选一构筑；通关解锁无尽模式。

## 解谜（每幕一个，嵌在波次之间）

1. **踏符阵**（一幕）：记住四个符亮起的顺序，再依次踏上去。踏错，会惊醒别的东西。
2. **双生祟**（二幕）：它免疫一切非封印伤害，而且只圈住一个封不住——必须用同一道印同时圈住双生两个。拖太久，它们会合体。
3. **契文三问**（三幕）：站进你认为正确的答案圈里停满两息。答对，终局的他弱一截；答错，他强一截，还会立刻招来讨债影。

## 联机（双人合作）

- **在线双人**：一人在主菜单点「建房联机」拿到 4 位房码，同伴输入房码点「加入房间」；房主点「开始送契」即可同行。房主权威同步，不需要自建服务器。
- **同屏双人**：同一台电脑，开局后按 Enter 加入。P1：WASD＋J/K/L＋空格；P2：方向键＋小键盘 1/2/3（或 , . /）＋右 Shift。
- 双人各自绕圈封印（红砂 / 青砂），命债全队共享，升级全队生效。**队友倒地后，绕着他合上一道印，就能把他从「那边」拉回来**（35 秒内）。

## 操作

- 电脑：WASD / 方向键移动绕圈，空格冲刺，J / K / L 借咒（也可点右侧按钮）
- 手机：左半屏虚拟摇杆绕圈，右侧大按钮；联机时客人的输入会回传房主

## 怎么玩到它

1. **在线**：打开 GitHub Pages 地址，手机与电脑均可。
2. **装成软件**：在浏览器菜单选「添加到主屏幕 / 安装应用」，之后离线可玩（PWA）。
3. **完全离线**：下载仓库里的 `tomorrow-debt-offline.html` 单文件，任意设备直接打开即玩，不需要网络。
