# 明日债 · Tomorrow's Debt

一款独立网页游戏。**向未来的自己借力量打怪，借过的每一招，稍后都会由「讨债影」拿来打你。**

## 玩法

- 你是时契行的送契人，要把《明日契》送过三幕：霓虹废城 → 深海遗迹 → 熔核天穹。三幕题材各异，同一条主线、同一身构筑与债务贯穿到底。
- 三件强力技能（星爆 / 环刃 / 时缓）随借随用，但每借一次记一笔债：约 22 秒后，一只「讨债影」会带着你借的那件技能来讨债。
- 最终 Boss「大讨债影」的技能组 = 你全程借过的技能集合。借得越少，终局越轻。
- 每波结束三选一构筑；通关解锁无尽模式。

## 操作

- 电脑：WASD / 方向键移动，空格冲刺，J / K / L 借技能（也可点右侧按钮）
- 手机：左半屏虚拟摇杆，右侧大按钮

## 怎么玩到它

1. **在线**：打开 GitHub Pages 地址，手机与电脑均可。
2. **装成软件**：在浏览器菜单选「添加到主屏幕 / 安装应用」，之后离线可玩（PWA）。
3. **完全离线**：下载仓库里的 `tomorrow-debt-offline.html` 单文件，任意设备直接打开即玩，不需要网络。
