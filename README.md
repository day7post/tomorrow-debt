# 明日债 · Tomorrow's Debt

一款独立网页**恐怖悬疑解谜**游戏（v0.4「解契」）。**一封迟到三年的契，要送进一栋老居民楼——契主已经死了，债主是未来的你。**

世界观见 [LORE.md](LORE.md)（时契行设定集）。旧版的竞技场玩法保存在 git 标签 `v0.3.1`。

## 玩法（第一章《老居民楼》）

- **点击探索**：在写实的 2D 场景里点发光处调查——老居民楼的楼道、客厅、卧室，信箱里的旧明信片、停了三年的挂历、医院走廊的录像。
- **一条咬合的谜题链**：门锁密码（搬家那一天）→ 分闸送电 → 遥控器与录像（他留给你的话）→ 挂钟 3:15（暗格）→ 病历本（入院日期）→ 保险箱 → 拼合被撕成两半的契文。
- **点烛记序**：把契放到遗像前之后，按烛火亮起的顺序把烛点回去。
- **封门画符**：最后在门上画一个闭合的圈，圈住契纹，把「未来的周守义」封回门后。
- **借命系统**：任何一道锁都可以借命硬闯——烧锁、引光、烧保险箱、换强提示、稳印。但每借一笔，记一笔命债，贯通三章，决定终局。
- 卡住时点右上角「提示」：第一层免费，第二层要借命。「笔记本」记着行规、本案档案和你找到的每条线索。

## 多人合作（1–4 人，难度随人数上升）

- **在线联机**：一人在主菜单点「建房联机」拿到 4 位房码，同伴输入房码「加入房间」（最多 4 人）；房主点「开始送契」。房主权威状态同步，不需要自建服务器。客人中途加入也会立刻同步进度。
- **难度缩放**：人数越多——契文的下半页在别人手里，**只能听他念给你听**；要同时合上的分闸越多（4.5 秒内先后合上）；点烛的顺序越长。
- **同屏共玩**：一台设备轮流点按即可（按 1 人难度）。

## 怎么玩到它

- 在线：<https://day7post.github.io/tomorrow-debt/>
- 离线：仓库里的 `tomorrow-debt-offline.html` 单文件，下载到手机/电脑直接打开即可玩（无需联网、无需翻墙）。
- 也可以把在线版「添加到主屏幕」装成 App（PWA），装过一次后离线可玩。

操作：鼠标或触摸点按即可，没有别的键位。
